  src/lib/firestore.ts
  ────────────────────────────────────────────────────────────────────────────
  Firebase config & Firestore operations:
  - syncUserProfile()       — Creates/updates user document in 'users/{uid}'
  - saveRoadmapToCloud()    — Saves roadmap to 'users/{uid}/roadmaps/'
  - updateRoadmapInCloud()  — Updates an existing roadmap document
  - getUserRoadmaps()       — Fetches all roadmaps for a user (ordered by date)
  - deleteRoadmapFromCloud() — Deletes a single roadmap
  - deleteAllUserRoadmaps() — Batch deletes all user roadmaps
  - saveProgressToCloud()   — Saves progress to 'users/{uid}/progress/{roadmapId}'
  - getProgressFromCloud()  — Retrieves progress for a specific roadmap
  - getAPIKeys()            — Searches 'progress/keys' and 'config/keys' docs
                              for API key pool. Throws if permission denied.

  7. AUTH FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. User clicks "Start Journey" (Landing) or "Get Started" (navbar)
  2. signInWithPopup(auth, googleProvider) called
  3. onAuthStateChanged fires in App.tsx:
     a. Sets user, enables UI, sets view='home'
     b. syncUserProfile() — saves user to Firestore (Background)
     c. getAPIKeys() — tries to read API keys from Firestore (Background)
        - Searches 'progress/keys' then 'config/keys'
        - If permission denied, throws error (caught, logged as warning)
        - If successful, sets keys for Gemini API
  4. User lands on Home page with floating glass bar + content

 Notes:
 - 8-second safety timeout on auth loading spinner
 - Errors from getAPIKeys() are caught and logged but not shown to user
 - If Firestore rules don't allow reading 'progress/keys' or 'config/keys',
   the getAPIKeys() call will fail silently with a console warning
